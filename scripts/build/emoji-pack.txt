# Manifest for scripts/build/gen-emoji-pack.py — the optional SD-card emoji pack.
#
# For the whole upstream set, run:
#   python3 scripts/build/gen-emoji-pack.py --all
# which takes every eligible single-codepoint Noto emoji and all country/region
# flag pairs from Unicode's emoji list.
#
# This manifest is for hand-picking instead:
#
#   <category>  <codepoints>  <source>
#
# category    faces gestures hearts symbols objects animals activity special food places flags extra
#             Picker entries are slotted into the matching built-in group;
#             "extra" lands after every other group.
# codepoints  '+'-joined hex. Multiple codepoints = one picker item. Regional
#             country pairs and supported UK subdivision flags use unique keys;
#             other sequences use the lead codepoint. Include FE0F selectors if
#             the emoji uses them, or the sequence you type won't match.
# source      A noto-emoji png/128 filename stem (FE0F selectors omitted, that's
#             how Noto names the files), or "flag:XX" for an ISO-3166 alpha-2
#             country or a supported subdivision code such as "flag:gbeng".
#
# A codepoint already baked into the firmware is a no-op — the baked art wins —
# and the generator warns about it. 512 KB hard limit, ~768 bytes per glyph.

faces     1f978       1f978   # disguised face
gestures  1f90c       1f90c   # pinched fingers
animals   1f98a       1f98a   # fox
animals   1f9a5       1f9a5   # sloth
objects   1f52d       1f52d   # telescope
objects   1f9ed       1f9ed   # compass
objects   1f6e0+fe0f  1f6e0   # hammer and wrench
activity  1f3d5+fe0f  1f3d5   # camping
activity  1f3d4+fe0f  1f3d4   # snow-capped mountain
activity  26f7+fe0f   26f7    # skier
extra     1f6f0+fe0f  1f6f0   # satellite
flags     1f1e9+1f1ea  flag:DE   # Germany
flags     1f1eb+1f1f7  flag:FR   # France
